3.4 Computation
We also made quicker calculations possible by using an 
online updating algorithm. This made calculating the resid-
ual parameters take a time complexity of O(1) instead of the 
usual O(N ). As explained in Section 3.2, we first transform 
the offline initialization data to a change-rate trend vector 
c and residual trend vector r, and then test it online using 
sequential ESD. During the transformation for the within-k2 
trend vector, we need to compute linear-regression 
parameters which would normally take a time complex -
ity of O(N ). However, since the residuals are calculated 
sequentially one by one and only one value changes from 
the previous vector that we calculated the parameters with, 
we use an online updating algorithm for faster calculation.
For that purpose, when feeding new xi+k2  into Xi|k2  and 
making Xi+1|k2 , we calculate new values from the previous

The time complexity per step involves trend vector 
updates and sequential detection. Both trend vectors are 
updated in O(1) time. Specifically, the change-rate involves 
a simple slope calculation in ( 3), and residual parameters 
follow the update rules in (9)–(11). Following these updates, 
the search for the maximum R statistic within a window of 
size N requires O(N ) operations. Since this search repeats 
up to r times, the formal per-step complexity is O(r · N ).
Because N and r are fixed parameters independent of the 
stream length T, the algorithm scales linearly with data vol-
ume, leading to an overall time complexity of O(T · r · N )
. Regarding memory, the algorithm only maintains the cur -
rent sliding windows and associated vectors, which keeps 
the space complexity at O(N ).
